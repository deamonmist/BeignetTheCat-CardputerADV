# BeignetTheCat-CardputerADV
If you want to watch a relaxing little creature lounge about and slam cookie after cookie with your CardputerADV, you are in the right place!

Beignet is made for the CardputerADV. If you want him for another device, let me know and I may add support.

Installation on the CardputerADV is simple.

1. Use M5 Burner to install Launcher for the Cardputer ADV, get that software here: https://docs.m5stack.com/en/uiflow/m5burner/intro.
2. Place the SD card you are using with your Cardputer ADV into your computer or other device.
3. Copy "Beignet_CardputerADV.bin" onto that SD card. I usually use a folder to contain all of my .bin files.
4. Put the SD card back into your Cardputer ADV and turn it on.
5. Immediately press enter to go to the Launcher app.
6. Select SD and navigate to Beignet_CardputerADV.bin.
7. Select Beignet_CardputerADV.bin and hit enter, then click Install.
8. That's it! It'll be the default program until you install another.
